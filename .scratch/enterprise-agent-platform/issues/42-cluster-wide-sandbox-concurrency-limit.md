# 42: 全系統跨 Worker 沙盒容器上限（審查後續：09）

**What to build:** 不論部署幾個 API Worker，同時執行中的沙盒容器總數都不超過設定的上限。目前 Semaphore 只在單一程序內，多 Worker 時實際上限是「Worker 數 × 4」。超過上限的呼叫排隊等待，等待逾時則回傳清楚的繁中訊息。
