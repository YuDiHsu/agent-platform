# 33: 個人工作區名單整併（審查後續：08）

**What to build:** 「這個角色在某使用者工作區中的樣子」成為一個值（角色 + 該使用者的設定），名單、Agent API、對話 bootstrap 都用它取得顯示名稱、提示詞與啟用狀態。「是否為預設角色」與「沒有個人設定時視為啟用」各只定義一次；預設角色代碼清單只有一個來源（種子），前端與測試不再手抄。Agent API 與 Studio 頁面依職責拆分。使用者看到的工作區行為不變。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 預設角色判斷、啟用預設值、顯示名稱／提示詞解析各只有一份實作
- [ ] `(角色, 個人設定)` 以單一值物件傳遞，取代多處各自拆解
- [ ] 預設角色代碼清單由種子單一提供；Studio 與種子測試改為引用或由 API 取得
- [ ] Agent API 拆為工作區名單、預設還原、記憶清理、Session 刪除等獨立模組；Studio 頁面拆出名單、記憶清理元件
- [ ] 載入或建立個人設定的輔助函式改為清楚的名稱；精靈中工具／規則／技能的勾選切換共用一個輔助
- [ ] 08 的測試不改斷言即全綠；tsc 乾淨
