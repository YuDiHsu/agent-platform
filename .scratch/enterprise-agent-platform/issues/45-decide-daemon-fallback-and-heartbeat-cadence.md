# 45: 決策：瀏覽器掛載離線時是否由 Daemon 接手，以及排程頻率範圍（審查後續：10）

**What to build:** 由人決定以下三項 10 實作後仍待定的行為，並把決定記錄為 ADR 或規格修訂；需要改程式的項目另開實作 ticket。

1. **瀏覽器掛載離線時改由 Daemon 接手**：規格寫「當使用者終端已啟動選配的 `Local MCP Daemon` 時，無縫由 Daemon 接手本機檔案讀寫」。目前只有透過 Daemon 配對建立的掛載才走 Daemon；`BROWSER_FS_API` 掛載離線時一律休眠為 `WAITING_BROWSER`。Daemon 服務的資料夾不一定是使用者在瀏覽器授權的那一個，自動改走 Daemon 可能讀到另一個資料夾。選項：維持現狀；或在配對時讓使用者明確把某個瀏覽器掛載綁定到某個 Daemon，綁定後才可接手。
2. **同一天改到較晚時間**：建立、改時間或重新啟用排程時，若當天時間已過，當天會被標記為已觸發。若使用者在 10:00 把 08:30 的排程改成 23:00，當天 23:00 不會執行。這樣是否可接受？
3. **排程頻率**：規格寫「週期性背景工單」，目前只支援每天一個時間。是否需要每週特定星期、每天多個時段或 cron 表示式？

**Blocked by:** None (can start immediately)
