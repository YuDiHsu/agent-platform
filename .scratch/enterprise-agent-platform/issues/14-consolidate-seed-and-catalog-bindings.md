# 14: 種子與目錄綁定整併（審查後續：01、04）

**What to build:** 開發者新增一種種子資產（角色、規則、技能、工具）時，只需描述「資產欄位 + 綁定關係」，不必再複製一份 upsert 與綁定迴圈。目錄的角色↔規則／技能／工具綁定對照只有一個來源，種子與 Studio 目錄讀取都用它。外部行為（種子結果、目錄 API 回應）完全不變。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 角色、規則、技能、工具四種種子共用同一個 upsert 形狀（以 `code` 為鍵、更新既有列、補 embedding），不再各寫一份
- [ ] 種子與目錄讀取共用同一份角色綁定對照，不再各自建 map
- [ ] 以 `by_right` 布林旗標切換方向的綁定對照函式改為兩個意圖清楚的命名（例如「依角色查資產」與「依資產查角色」）
- [ ] 移除未被使用的 session 依賴注入與 engine 重設輔助函式（確認無測試或啟動流程引用）
- [ ] 測試中重複的工具／角色建立 fixture 合併為共用 fixture
- [ ] 種子重跑仍為冪等；完整測試套件、mypy、tsc 全綠
