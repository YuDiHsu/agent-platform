# 35: 一鍵還原預設角色時一併恢復預設綁定（審查後續：08）

**What to build:** 使用者在 Studio 對某個預設角色（或全部 7 個）按「還原預設」後，該角色在其工作區內的 Rules／Skills／Tools 綁定恢復為種子預設值。目前還原只重新啟用角色、取消移除並清空名稱／提示詞覆寫，個人調整過的綁定不會回來。

**Blocked by:** 33: 個人工作區名單整併

**Status:** ready-for-agent

- [ ] 還原單一或全部預設角色時，該使用者的規則、技能、工具綁定與開關回到種子預設
- [ ] 還原只影響發起者的工作區
- [ ] 測試：調整綁定 → 還原 → 綁定等於種子預設；其他使用者不變
- [ ] 瀏覽器驗證還原後 Studio 顯示的綁定
