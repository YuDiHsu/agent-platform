**What to build:** 使用者在 CLI 審批卡修改 `cli_args` 後送出，系統以新參數重新驗證與渲染指令，審批卡預覽、審批紀錄與實際執行的都是同一條新指令。若新參數驗證失敗或觸發黑名單，審批卡顯示拒絕原因，使用者可再修改。目前儲存的 `rendered_command` 會過期，核准的與執行的可能不同；重新渲染被拒時前端毫無提示。
